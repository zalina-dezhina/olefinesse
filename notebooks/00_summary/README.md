# 00_summary/ (Fleet)

**EN:** Fleet summary — run ONCE after all 7 furnaces have completed stages 00b through 03. Aggregates results, compares furnaces, identifies outliers. Input to the forecaster.

**RU:** Сводка флота — запускается ОДИН РАЗ после того как все 7 печей завершили стадии 00b–03. Агрегирует результаты, сравнивает печи, выявляет выбросы. Входные данные для форсайтера.

**Prerequisite / Предварительное условие:** all 7 furnaces must have `output/{F}/02a_corr_furnace/` populated.
