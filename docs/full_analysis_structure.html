7
FurnacesПечей
1HA · 1HB · 1HC · 1HD · 1HE · 1HF · 1HG
Why 7 separate? Each furnace runs independently. Different operators, conditions, coking rates. Never average raw correlations across furnaces without first confirming they behave the same. Почему 7 раздельно? Каждая печь работает независимо. Разные операторы, условия, скорости коксования. Никогда не усреднять сырые корреляции по печам без подтверждения одинакового поведения.
4
Passes / furnaceПасса / печь
A · B · C · D
48 tubes each · independent feed + steamтрубок · независимая подача + пар
Why passes matter? Each has own feed + steam control. One pass can coke faster if it gets less steam. Analyse furnace-wide FIRST — pass differences are secondary and smaller. Почему пассы важны? У каждого своя подача + пар. Один пасс коксует быстрее при меньшем паре. Сначала вся печь — различия пассов вторичны и меньше.

4 — Key rules: when to merge, when to keep separate4 — Ключевые правила: когда объединять, когда держать раздельно
Furnaces — always separate firstПечи — всегда раздельно сначала
Run notebooks 00b→03 independently per furnace. Merge into fleet/ only to pool trajectories for the forecaster. Never average raw correlations across furnaces.Запускать ноутбуки 00b→03 независимо на каждую печь. Объединять в fleet/ только для траекторий форсайтера. Никогда не усреднять сырые корреляции по печам.
Passes — furnace-wide first, per-pass secondПассы — сначала вся печь, потом по пассам
Start with dd_abs_max (all passes). Move to dd_abs_max_A/B/C/D only after you understand the furnace picture. Pass differences are smaller than furnace differences.Начинать с dd_abs_max (все пассы). Переходить к dd_abs_max_A/B/C/D только после понимания картины печи. Различия пассов меньше различий печей.
Cycles — pool for correlations, separate for trajectoriesЦиклы — вместе для корреляций, раздельно для траекторий
For correlations: pool all 16 cycles (one DataFrame per furnace). For trajectories: keep each cycle indexed by run_age_days so you can overlay and compare them.Для корреляций: объединить все 16 циклов (один DataFrame на печь). Для траекторий: хранить каждый цикл с индексом run_age_days для наложения.
Output rule: file lives where its data came fromПравило файлов: файл там откуда его данные
Only 1HA data used → output/1HA/. Required ≥2 furnaces → output/fleet/. Pass identity mattered → .../02b_corr_passes/. Clean once in 00b. Analyse many times in 01–05. Never query Databricks after 00b.Только данные 1HA → output/1HA/. ≥2 печей → output/fleet/. Важен пасс → .../02b_corr_passes/. Очистить один раз в 00b. Анализировать многократно в 01–05. Никогда не запрашивать Databricks после 00b.
